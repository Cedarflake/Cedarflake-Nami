# 查看统计

统计页不是传统的网站分析工具。它只回答和重定向有关的问题：哪些规则被请求、请求从哪个 Runtime 域名进入、其中有多少像真实浏览器访问，又有多少像机器人或探测。

启用统计存储和 Runtime 的事件投递后，打开侧栏中的**统计**即可看到数据。

## 先看两个数字

**已匹配请求**是 Runtime 实际观测到并写入统计的规则命中次数。机器人、链接预览和普通浏览器都在里面。

**有效访问**是根据请求分类估算的人类入口访问。它会排除已声明机器人、疑似机器人、链接预览和已验证的短链接续跳，所以通常小于已匹配请求。

这两个数字没有谁更“正确”：前者回答 Runtime 实际处理了多少次规则命中，后者试着回答有多少次更像人主动打开链接。

## 时间范围按设备时区显示

- **1 天**是从当前时刻向前滚动 24 小时，趋势按小时显示；
- **7、30、90 天**按当前设备的 IANA 时区划分自然日；
- 图表提示和横轴日期也使用这个设备时区。

如果刚切换时区或第一次打开统计页，页面会记录新的时区并重新查询。看到旧边界时先刷新一次，再判断数据是否真的错位。

## 入口域名不是规则分组

侧栏中的入口域名表示请求实际到达了哪个 Runtime 主机，例如 `i0c.cc`、`vc.i0c.cc` 或 `nf.i0c.cc`。

选择一个域名后，卡片、趋势、热门路由和各项细分都会使用同一范围。“全部入口域名”是这些主机的合计；“未识别域名”用于不属于配置基础域名及其子域名的事件。

## 热门路由的变化怎么看

热门路由按所选周期内的有效访问排序，并与前一个等长周期比较。例如选择 7 天，就与再往前的 7 天相比。

上一周期没有有效访问时，页面不会用 0 当分母计算一个夸张百分比，而是显示“上一周期无请求”。本周期也为 0 时显示持平。

点进一条路由可以查看它自己的趋势和聚合维度。只要编辑规则时保留同一个统计 ID，修改路径或目标不会把后续数据拆成另一条链接。

## 机器人视图先看观测值

底部的**机器人**视图把已声明机器人、疑似机器人、未匹配路由和处理错误放在一起。

大号数字是数据库实际收到的观测样本。未匹配和系统事件会抽样上报，下方的估算值才是根据采样率还原的参考总量。疑似机器人只是分类结果，不等于已经确认的机器人。

## 为什么刷新后数字才变化

统计查询会短暂缓存 15 秒，让时间范围和域名切换更快。需要立刻核对新事件时，点击页面顶部的刷新按钮；这会重新查询数据，不会重新发送或修改已有事件。

浏览器也可能缓存永久重定向。访问没有再次到达 Runtime 时，统计自然不会增加，这和统计查询缓存是两回事。

## 隐私与保留期

事件不保存 IP、完整 User-Agent、完整来源 URL、目标地址、原始查询参数或原始未匹配路径。原始事件和幂等记录保留 181 天，小时与天级聚合继续保留。

需要核对事件字段、归因、采样算法、时间桶和数据库保留行为时，再看[统计口径参考](/zh-CN/reference/analytics)。
