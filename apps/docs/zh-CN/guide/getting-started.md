# 了解这个项目

i0c.cc 是服务于 Revaea 的个人边缘重定向实验项目。它把数据库驱动的控制面、可选的边缘 Runtime、可选统计和编译期扩展放在同一个仓库中。

它不提供注册即用的托管短链接服务，也不以企业级重定向平台为目标。仓库中的插件和 SDK 只服务当前 Workspace，没有作为公开包发布的计划。文档主要说明现有实例的工作方式，并提供自行部署所需的步骤。

## 适用场景

假设你希望：

```text
https://go.example.com/docs  →  https://docs.example.com
```

在 WebUI 中创建 `/docs` 规则后，规则和版本历史会保存在数据库中。部署在边缘平台上的 Runtime 接收 `go.example.com` 的公开请求，并返回跳转或反代响应。

## 主要组成

- **WebUI** 是管理入口，用于登录、编辑规则、修改设置和查看统计。
- **数据库** 保存可以修改的数据。默认可以使用 PostgreSQL，也可以改用 Cloudflare D1。
- **Runtime** 处理访客请求。Cloudflare、Vercel 和 Netlify 是三个备选平台，第一次部署只需选择一个。

WebUI 会把数据库中的配置整理成一份经过校验的快照。Runtime 只读取这份快照，不需要数据库账号或连接地址。

## 功能范围

最常见的用途有三种：

- 把一个短路径跳转到完整地址，例如 `/docs` 跳到项目文档；
- 把一整段旧路径迁到新站，例如 `/old/*` 跳到新的目录结构；
- 透明反代一个上游，让浏览器地址栏继续显示 Runtime 域名。

统计是可选的。启用后可以查看已匹配请求、估算的有效访问、入口域名和机器人流量；它不会保存 IP、完整 User-Agent、完整来源 URL 或原始查询参数。

## 适用范围

i0c.cc 主要用于 Revaea 的基础设施和个人工程实验，也适合希望研究或自行部署这套实现的开发者。

使用者需要自行部署各个组件并管理配置。插件在构建时组合，切换数据库提供方也不会自动搬运已有数据。
