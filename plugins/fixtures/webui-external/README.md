# External WebUI extension fixture

This private package simulates an independently authored WebUI extension. It uses `@nami/plugin-sdk/webui`, and its separate static installation config proves that the WebUI extension registry can consume an extension without changing the host component source.

It is a test fixture under the plugin subsystem, not a supported user-facing plugin. The package uses the repository Apache-2.0 license.
